# ☕ Java Mini Projects Collection

A collection of beginner-friendly Java console applications developed using Object-Oriented Programming (OOP) concepts.
These projects are useful for learning Java fundamentals, classes, inheritance, abstraction, arrays, collections, and menu-driven applications.

---

# 📂 Projects Included

## 1️⃣ Bank Management System

File: `BankApp.java`

### Features

* Create bank account
* Deposit money
* Withdraw money
* Check balance
* Menu-driven console application

### Concepts Used

* Classes & Objects
* Encapsulation
* Constructors
* Methods

# ▶️ How to Run

## Step 1: Compile the program

```bash
javac FileName.java
```

Example:

```bash
javac ShoppingApp.java
```

---

## Step 2: Run the program

```bash
java FileName
```

Example:

```bash
java ShoppingApp
```
