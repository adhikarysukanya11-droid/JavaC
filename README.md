# 🏦 Bank Management System in Java

A simple console-based Bank Management System developed using Java.
This project allows users to create an account, deposit money, withdraw money, and check account balance through a menu-driven program.

---

## 📌 Features

* Create a bank account
* Deposit money
* Withdraw money
* Check current balance
* Simple menu-driven interface
* Input validation for deposits and withdrawals

---

## 🛠️ Technologies Used

* Java
* OOP Concepts
* Scanner Class
* Console Application

---

## 📂 Project Structure

```bash
BankApp.java
```

The project contains the following classes:

* `Account` → Handles account details and balance operations
* `Transaction` → Manages deposit, withdrawal, and balance display
* `BankApp` → Main application with user interaction menu

---

## ▶️ How to Run

### Step 1: Compile the program

```bash
javac BankApp.java
```

### Step 2: Run the program

```bash
java BankApp
```
